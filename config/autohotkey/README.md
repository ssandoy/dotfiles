# AutoHotkey

Windows mappings for typing Norwegian letters on a US keyboard.

## Mappings

- `Left Alt+O` / `Right Alt+O` / `AltGr+O` -> `ø`
- `Left Alt+E` / `Right Alt+E` / `AltGr+E` -> `æ`
- `Left Alt+A` / `Right Alt+A` / `AltGr+A` -> `å`
- Add `Shift` for uppercase variants.

## Setup

Install AutoHotkey v2, then run:

```powershell
%USERPROFILE%\.config\autohotkey\norwegian-us.ahk
```

To start it automatically, add a shortcut to this script in the Windows Startup
folder.
